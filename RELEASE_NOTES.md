# Tally by Rayxworld v1.0.2

- Added recursive scanning of standard personal folders with protected
  directories and detected software projects left untouched.
- Added source/destination previews and separate approval for every destination
  group; stale previews are rejected.
- Shows reasons for skipped items and scan errors, and lets users add a routing
  rule for unsupported file types.
- Fixed CLI installation in the signed Windows installer.

Users moving from the original v1.0.0 installer need to uninstall it first,
then install this updater-ready release once. Future signed releases can be
checked and installed from Settings.
